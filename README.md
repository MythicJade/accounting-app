# 我的记账 2.5.0

一款个人离线优先的记账 PWA。账目默认保存在浏览器 IndexedDB 中，不需要账号或后端服务。

## 2.5.0 账目正确性、备份与体验

- 修复修改金额仍保存旧金额、账户选中状态不一致、连续点击重复保存的问题。转账、编辑、删除均按整数分重新计算余额；无效流水不再提前改变账户期初日期。
- 备份格式升级到 v4：一致性快照、SHA-256 文件完整性校验、笔数/收支预检。完整恢复不再误删同日同额的真实流水；合并按稳定标识识别同一笔流水，遇到内容或期初余额冲突时中止，不猜测覆盖。
- 支持旧版 JSON 备份。旧备份和表格导入按记录时间及重复次数匹配，不再将文件中同样的两笔消费合成一笔。导入缺少账户、日期不合法或非零期初余额日期冲突时，整批中止并说明原因。
- 新增最近 3 个本机恢复点：每天首次修改流水/账户/分类/预算以及导入、恢复、删除流水等操作前留档。恢复点写入失败会中止对应操作，不会跳过保护。设置页显示上次导出时间并提供恢复入口。
- 统一明暗主题、字号、触控区域和卡片层级；以逻辑视口适配高分辨率长屏，并在小屏允许安全滚动。图表旋转时标题不再跟转，支持打断动画；所有动画尊重系统“减少动态效果”。
- 最近 200 条流水改用索引读取；年度资产趋势仅读取一次账本；统计筛选单次读取、图表点选局部重绘。快速切页串行清理，避免旧页面内容覆盖新页面。
- PWA 更新改为用户确认后生效，编辑页面不强制刷新。Excel 库纳入离线缓存。安卓版本 2.5.0 / versionCode 20500，沿用原应用包名及签名。

### 升级与备份提示

1. 升级前先导出 JSON 备份，并确认文件已存到手机文件或其他安全位置。加密密码请单独保存，忘记后无法找回。
2. 安卓使用原签名覆盖安装，不要卸载旧版。网页版与安卓 APK 的本地数据相互独立，首次迁移需手动导出/导入 JSON。
3. 本机恢复点仍保存在同一个数据库，**不能防止清除站点数据、卸载、手机损坏或丢失**。导出记录只表示已发起下载/分享，不保证用户已经保存文件。
4. 2.5 会保留原有记录并为流水补充稳定标识，但不会猜测或重建旧版本已经丢失的账目；如曾遇到错误，请核对原始备份。

- 全面更新暖黄色点睛的视觉系统，统一卡片、间距、字体层级与轻量动效。

## 2.0.0 重点改进

- 金额统一以整数“分”存储，避免浮点累计误差。
- 日期按本地日历日处理，修复月末统计和 Excel 导出日期偏移。
- JSON 与 Excel 导入增加预检、去重、引用校验和事务回滚。
- JSON 备份可选择使用密码进行 AES-GCM 加密。
- 账户和分类支持归档；有关联流水时不再允许直接删除。
- 期初余额增加生效日期，资产趋势支持跨年度结转。
- 增加首次使用引导，以及完整流水的搜索、筛选和分页。
- PWA 更新在刷新前提示，Excel 组件改为首次使用时按需缓存（首次使用需要联网）。

## 本地运行

本项目是静态应用，但浏览器的模块、IndexedDB 和 Service Worker 需要通过 HTTP(S) 访问：

```bash
python -m http.server 8080
```

打开 `http://localhost:8080/`。安装到手机主屏时，请部署到支持 HTTPS 的静态托管服务。


## 数据升级与恢复

首次打开 2.0.0 时会自动把旧金额迁移为整数分，并为旧账户推导期初日期。迁移是幂等的，原有流水 ID 和关联关系会保留。

重要数据建议定期从“我的 → 导出备份”生成加密 JSON，并将密码与备份文件分开保管。忘记加密备份密码后无法恢复。
