# 我的记账 2.4.0

一款个人离线优先的记账 PWA。账目默认保存在浏览器 IndexedDB 中，不需要账号或后端服务。

## 2.4.0 动效与记账体验优化

- 页面切换增加轻量进入过渡，主要卡片与记账按钮分层出现，减少界面突跳。
- 新增记账页补充类型切换、金额输入、分类与账户选择反馈，操作状态更清晰。
- 动效统一使用短时长与 GPU 友好属性，并自动尊重系统“减少动态效果”设置。
- 延续短屏分类、账户和键盘完整可见的 V2.3.2 布局修复。

## 2.3.2 移动端记账页修复

- 分类图标改为受控尺寸，不再随屏幕宽度无限放大。
- 短屏自动压缩间距和数字键盘，账户、日期、备注与完成按钮保持完整可见。
- 账户选择行禁止被弹性布局压扁，长屏布局也更加均衡。
- 同步 Web、Service Worker、依赖锁文件与 Android 版本号。

## 2.1.1 可用性修复

- 添加页分类改为稳定的单行分页，支持滑动、圆点和前后按钮，较矮视口也不会裁切。
- 修复选择后错误跳回分类第一页的问题，并保留当前分类页。
- 新增完全离线的原创线性 SVG 分类图标，统一首页、流水、统计与分类管理的图标风格。
- 收紧首页、账户、资产、统计及设置页的字号、卡片高度与间距。

## 2.1.0 视觉更新

- 全面更新暖黄色点睛的视觉系统，统一卡片、间距、字体层级与轻量动效。
- 重塑首页月度概览、预算进度、搜索入口和流水卡片，增强金额与账户信息层级。
- 优化账户资产卡、资产趋势、统计图表及固定记账面板的移动端体验。
- 保留离线存储、加密备份、数据迁移与完整流水管理等 2.0.0 功能。

## 2.0.0 重点改进

- 金额统一以整数“分”存储，避免浮点累计误差。
- 日期按本地日历日处理，修复月末统计和 Excel 导出日期偏移。
- JSON 与 Excel 导入增加预检、去重、引用校验和事务回滚。
- JSON 备份可选择使用密码进行 AES-GCM 加密。
- 账户和分类支持归档；有关联流水时不再允许直接删除。
- 期初余额增加生效日期，资产趋势支持跨年度结转。
- 增加首次使用引导，以及完整流水的搜索、筛选和分页。
- PWA 更新在刷新前提示，Excel 组件改为首次使用时按需缓存（首次使用需要联网）。

## 本地运行

本项目是静态应用，但浏览器的模块、IndexedDB 和 Service Worker 需要通过 HTTP(S) 访问：

```bash
python -m http.server 8080
```

打开 `http://localhost:8080/`。安装到手机主屏时，请部署到支持 HTTPS 的静态托管服务。

## 检查与测试

需要 Node.js 20 或更高版本：

```bash
npm run check
npm test
```

测试覆盖金额精度、本地日期边界、加密备份往返，以及版本和离线缓存清单一致性。

## 数据升级与恢复

首次打开 2.0.0 时会自动把旧金额迁移为整数分，并为旧账户推导期初日期。迁移是幂等的，原有流水 ID 和关联关系会保留。

重要数据建议定期从“我的 → 导出备份”生成加密 JSON，并将密码与备份文件分开保管。忘记加密备份密码后无法恢复。
